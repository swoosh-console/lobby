The following flatpacks are required to run the system:

| Name                    | Program-ID                   | Version  | Explanation                   |
| ----------------------- | ---------------------------- | -------- | ------------------------------|
| Cemu                    | info.cemu.Cemu               | >=2.6    | Required to run WII U games.  |
| Dolphin Emulator        | org.DolphinEmu.dolphin-emu   | >=2606   | Required to run GC/WII games. |
| M64Py                   | net.sourceforge.m64py.M64Py  | >=0.3.0  | Required to run N64 games.    |
| Nestopia                | ca._0ldsk00l.Nestopia        | >=1.53.2 | Required to run NES games.    |
| PCSX2                   | net.pcsx2.PCSX2              | >=v2.6.3 | Required to run PS2 games.    |
| VisualBoyAdvance-M      | com.vba_m.visualboyadvance-m | >=2.2.2  | Required to run GBA games.    |
